# Derived publication results

These files contain non-identifying outputs from the rolling 2012-2023 causal experiment.

- `annual_sequential_bridge_results.csv`: cohort PMR, bridge coverage, operations, and boundary metrics.
- `aggregate_sequential_bridge_summary.json`: mass-weighted results and global UID audits.
- `boundary_nonreuse_audit.csv`: exact bridge consumption and residual carry by boundary.
- `cycle_phase_validations.json`, `path_phase_validations.json`: independent replay reports.
- `curves/`: daily cohort-attributed PMR trajectories.

Raw invoices and reversible entity mappings are not included.
